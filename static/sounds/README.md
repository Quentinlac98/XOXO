# Sons — Gossip Girl Party

Dépose ici tes fichiers audio :

| Fichier | Déclencheur |
|---------|-------------|
| `xoxo.mp3` | Nouveau scoop affiché sur le projecteur |
| `quiz_start.mp3` | Lancement d'un nouveau quiz |
| `question_tick.mp3` | Countdown de la question (optionnel) |
| `correct.mp3` | Bonne réponse (son bref) |
| `new_gg.mp3` | Révélation du nouveau Gossip Girl |
| `phase2_start.mp3` | Début du Mode Libre |
| `timer_end.mp3` | Fin du timer 15 min |

Format recommandé : MP3, mono, < 500Ko par fichier.
